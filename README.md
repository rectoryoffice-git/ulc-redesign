# ULC.org Audit & Redesign Prototype

Public prototype of a redesign of ULC.org (Universal Life Church).

- **Landing page:** https://rectoryoffice-git.github.io/ulc-redesign/
- **Prototype:** [`redesign/`](redesign/index.html) — 9 static pages (HTML/CSS/JS, no build step). Forms don't submit.
- **Audit files** (full audit PDF, to-do list, walkthrough video) are in a Google Drive folder restricted to ULC Monastery accounts; they are not in this repository.

Audit: Claude, with input from two independent SEO specialists. Redesign: Claude, with design input and a freelance designer's contributions.
